# Rickroll

A simple website that plays a Rickroll video automatically with audio.

## Live Site

https://frictionalfor.github.io/rickroll/

## QR Code

Scan to open the site:

![QR Code](qrcode.png)

## Files

- `index.html` - page structure
- `style.css` - black and white styling
- `script.js` - autoplay and interaction handling
- `rickRollVideo.mp4` - the video
- `qrcode.png` - QR code for the site

## Run

Open `index.html` in a browser. The video plays automatically with sound.
